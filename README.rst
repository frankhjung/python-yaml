Processing YAML with Python
===========================

This is an example Python project to demonstrate:

* format and lint code using `Ruff <https://docs.astral.sh/ruff/>`_
* lint code using `PyLint <https://www.pylint.org/>`_
* lint YAML using `yamllint <https://yamllint.readthedocs.io/>`_
* report on test `coverage <https://coverage.readthedocs.io/>`_
* document using `Sphinx <https://www.sphinx-doc.org/>`_
* process YAML data using `PyYAML <https://pyyaml.org/>`_
* unit test using `pytest <https://docs.pytest.org/>`_
* manage dependencies and builds using `uv <https://docs.astral.sh/uv/>`_

Dependencies and Installation
-----------------------------

Project dependencies are defined in `pyproject.toml <./pyproject.toml>`_.
Synchronise the virtual environment using::

   uv sync
