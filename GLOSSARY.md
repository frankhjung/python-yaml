# Glossary

- **Employee**: A person working for the company, identified by a unique `id`
  and a `name`.
- **Turnover**: The financial value generated by an Employee in a given `year`.
- **Data-Oriented Architecture**: An architecture where data is represented as
  plain, immutable structures (e.g., tuples, frozen dataclasses) and business
  logic is implemented as pure functions that operate on this data without side
  effects.
